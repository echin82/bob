# Task: Review and refine feature specification
Validate the feature specification against a quality checklist, refine, and save the final version.

## Context
- delivery/specs/contract-risk-assessment/feature-spec.md

## Step 1: Review against checklist
Check whether:
- Goal and expected outcome are clearly defined
- Target users and scenarios are documented
- Scope and out-of-scope items are explicit
- Functional requirements are externally observable and independently testable
- Every major functional requirement has at least one acceptance criterion in Given / When / Then format
- Non-functional requirements include measurable thresholds
- Assumptions and open questions are captured with owner placeholders
- No API design, database schema, architecture diagrams, implementation tasks, or code

Return:
1. What is strong
2. What needs refinement
3. Suggested edits
4. Questions to resolve before moving to architecture

After presenting the review, ask: "Should I apply these refinements and save the final spec?"

## Step 2: Refine
Apply the refinements. Keep the spec concise and MVP-oriented.

## Output
Save refined spec to: delivery/specs/contract-risk-assessment/feature-spec.md
